## Summary

A standard spare-worker pool, built on #116's `spare` Now Kind. A spare is a parked worker with no lane, started in a typed turn, so a lane can start later while the user is away.

```text
typed turn:  coordinator offers spares (two unless the user names a number)
  start_session  key s<n>, branch lane-s<n>, no brief, Now Kind spare
  worker         status parked, "spare, waits for a brief"
  ready          Waiting: s1: spare, available: waits for a brief

a lane needs a worker (any turn, unattended too):
  coordinator    writes briefs/s<n>.md, sets Now Kind (pr unless run or audit) and Issues
                 sends GO #s<n>
  worker         reads the brief, runs the usual workflow; key, branch and status file stay s<n>

no lane left for it:
  coordinator    sends CLOSE #s<n>
  worker         one-line report, status done --branch none --head none
  ready          Finished (in Now), left out once moved to plan-history.md
```

`ready` changes:

```diff
 parked spare, no brief      Waiting: spare, available: waits for a brief
+spare with a brief          Inconsistent: set its Now Kind to its lane's
+                            (otherwise it would finish under Finished with no PR);
+                            done, it is checked as `pr`; blocked keeps its Waiting line
```
