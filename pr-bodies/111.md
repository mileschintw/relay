## Summary

After a compact, a plugin `SessionStart` hook (`compact` matcher) runs `tools/resume.py`. It finds the records folder and prints a resume note for the coordinator or the lane worker, so the user no longer pastes a compact instruction.

```text
SessionStart(compact) → resume.py (hook JSON on stdin: cwd)
  records = AGENTS.md/CLAUDE.md pointer line, else the worktree on [coord]
  worktree is Handover › Coordinator's
    → language line, mode (a compact keeps it), reread Handover (Next), Now, both Waiting;
      Read plan.md before editing it; relay.py's ready call and its Plan warning
  branch is a lane's (status/<key>.md)
    → language line, paths of briefs/<key>.md, status/<key>.md, reports/<key>.md
  else, or any failure → prints nothing (never blocks the session)
```

```diff
 plugin/
+├── hooks/hooks.json          # SessionStart, matcher compact → python3 -I resume.py || py -3 -I resume.py
 ├── tools/
+│   └── resume.py             # separate from relay.py (lane 108 was changing relay.py); reuses its project_line/line_path
 └── skills/
     ├── coordinate/
-    │   ├── compact.md        # pasted compact-instruction.md pointer (≤600 bytes)
+    │   ├── compact.md        # empty your head into the plan; the hook adds the resume note
     │   └── SKILL.md          # First turn step 5: a compact keeps Handover's mode
     └── setup/templates/README.md   # compact-instruction.md row removed
 README.md                    # Layout: resume.py, hooks.json rows

```

The skill is not injected again. Claude Code already re-attaches the invoked skill after a compact.

The coordinator approved the two edits outside the original file list: coordinate/SKILL.md First turn step 5, and docs/getting-started.md:35. Without them, step 5 would end unattended mode on every compact, because no pasted instruction would keep it on.

## Merge Danger

**Door:** two-way

Revert the PR to remove the hook; compact.md's old text comes back with it.

**Blast Radius:** every-compact

Every session with relay installed runs the hook after each compact. It costs one `python3`/`py` start and a few `git` calls (10 s timeout), and it prints nothing outside a relay coordinator or lane worktree. If neither `python3` nor `py` exists, the hook errors without blocking, and the session goes on without the note. Coordinators that relied on a pasted compact instruction just stop needing one.
