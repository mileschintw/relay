## Summary

Round-2 fixes to `plugin/tools/relay.py`:

- **merge** stops before any lookup when its `git fetch` fails. It names the fetch error, merges nothing and exits 1, instead of later reporting "merge-tree failed" against stale refs.
- **check_commands** takes an item's main command from the backticked spans outside its `(Windows: …)` override. `` (Windows: `b`) `a` `` now runs `a` on other systems. An item with only an override is a usage error naming the line (localcheck exits 2).
- **Deny list:** only an end of a match that is itself a word character needs a non-word neighbour. `\.internal` matches `build.internal` again and `@acmebot` matches `dev@acmebot` again (a regression from #83). `acme` still misses `acmecorp`.
- **localcheck** on a project.md that is not UTF-8 exits 2 with one line instead of a traceback (exit 1). The docstring's exit-2 list names the case.
- **ready:** Ready for GO reads the GitHub blocked-by of every issue on the brief's `Closes:` line (issue `<key>` when there is none), minus those issues. The brief's `Depends on:` applies only when every one of those lists is empty. The brief template's `Depends on:` placeholder now says "the GitHub blocked-by of every issue this lane closes".
