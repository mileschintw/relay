Two small `relay.py` fixes.

## Why

- **#147:** `ready` printed a blocked lane's `doing` line verbatim under Waiting. A deny-list name in it reached the output even though Records already flags the status file by line number, and the coordinator may copy that line into plan.md or a message.
- **#151:** `waitchecks` handed the checks to `gh pr checks --watch` with no overall timeout. A hung watch would never exit, so it would never wake the coordinator, and with the alarm now set only while a worker can move without the user, nothing else catches it.

## What changed

- `ready`: a blocked lane whose `doing` matches the deny list prints `<key>: blocked: (doing withheld: a deny-list name)`. While Records reports the deny list itself as unusable, it prints `(doing withheld: deny-list check not run)`, the same leak in a different place. Deny patterns are now compiled once per run.
- `run()` takes an optional `timeout` in seconds. Past it, the command is killed and `run` returns `TIMED_OUT`, without counting toward `ready`'s budget list. When `ready`'s deadline comes first, the deadline still wins.
- `waitchecks`: a watch still running after 20 CI start waits (2 hours with the default 6 minutes) is stopped. It prints the checks table and `the checks watch on PR #N ran past M minutes with no result; it was stopped`, then exits **5** with its own hint: rerun once, and if it exits 5 again, give the user its line and the table.
- The module docstring covers the withheld line, the watch timeout and exit 5. No skill text changed: skills reach exit codes through the `hint (exit N):` line, and only `ci-fallbacks.md` names one code (exit 3).

## Tests

- `test_blocked_lane_withholds_a_deny_list_name`: the name never appears, Records still names `status/12.md`, and a broken deny list withholds the line too.
- `test_a_watch_past_its_timeout_is_its_own_exit`: a 0.002-minute CI start wait and a fake `gh` watch that sleeps 30 s. Asserts exit 5, the table, the `ran past` line and the hint, in about 3 s.
- `test_a_command_timeout_kills_it_and_the_deadline_still_wins`: `run`'s own timeout, and the deadline winning when it comes first.
- `py -3 -I tests/test_relay.py` and `claude plugin validate .` both pass.
