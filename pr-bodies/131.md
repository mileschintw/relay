## Summary

`relay.py` now prints the 14 batch-H coordinator rules as hints beside the output they apply to. No new check, exit code or lookup: each hint is chosen from lines the command already prints.

```diff
 ready
   print_section(section, items)
     items
+    "  hint: ..." for each READY_HINTS row whose regex matches one of the items
 roadmap
   rows, Missing `## Files`
+  "hint: an empty Roadmap: ..." (only when there are rows)
 waitchecks / merge
   main() -> exit code
+  "hint (exit N): ..." on stdout, last (EXIT_HINTS)
```

Hint regexes are anchored to each line's own shape, so a blocked lane's `doing` text or a lookup failure never picks another kind's hint.

## Merge Danger

**Door:** two-way

Output-only lines; revert restores the old output.

**Blast Radius:** small

Nothing in the plugin parses `ready` output. A coordinator reading it sees `  hint:` lines among the section items; existing lines are unchanged. Hints go to stdout, so stderr (the one-line errors tests compare exactly) is unchanged.
