## Summary

The plan template no longer has a `Last updated:` line. The records commit time already records when the plan changed. *Plan* in `relay:coordinate` says so, and keeps its time command for the entries that carry a time.

`ready` now checks the hand-written records before anything else reads them:

```diff
 cmd_ready
+  check_encoding(plan.md, briefs/*.md, pr-bodies/*.md)   # -> "Records:" section
-  plan-limit count: read_text(utf-8)                    # crashed on a bad byte
+  plan-limit count: read_text(utf-8, errors="replace")
   per-lane lookups
```

The check warns, naming the file and line, about:

- invalid UTF-8 (only the first bad byte in a file);
- any control character except tab, LF, and a CR right before LF.
