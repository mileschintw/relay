## What

`relay.py ready` now warns when the git checkout that holds `project.md`'s **relay.py:** path is behind its `origin/<default>`. Since #24 that line usually points at the main checkout, which does not move when PRs merge, so everyone kept running an old `relay.py` with no sign of it.

The warning appears under a new `relay.py:` section, on one line with the count and the fix:

```
relay.py:
  D:/Repos/relay is 2 commits behind origin/main: git -C D:/Repos/relay merge --ff-only origin/main
```

## How

- `relay_py_behind(records, checkout)` runs right after `cmd_ready` fetches `--checkout`.
  - It reads the line with `project_line`. A relative path resolves against `--checkout`, else the current folder.
  - It finds the checkout with `git rev-parse --show-toplevel`.
  - It fetches that checkout when it is not `--checkout`, so the count is not stale.
  - It counts `HEAD..origin/<default>`.
- `line_path(value)` takes a leading backticked span, else the text before a trailing `(...)` note. A path like `C:/Program Files (x86)/...` stays whole.
- When that checkout is on a branch other than the default, the fix starts with `git -C <checkout> switch <default> &&`. A path with spaces is quoted.
- There is no check when the line is missing or `none`, when the path's folder is missing, or when the path is outside a git checkout.
- The module docstring documents the new section.

## Tests

The new tests in `tests/test_relay.py` sit next to the other `ready` tests. They use a local bare repo as `origin`, with no network:

- A separate checkout that is 2 commits behind gets one warning with the count. It is fetched even though `--checkout` is another clone.
- A relative path resolves against `--checkout`.
- A checkout on another branch whose path contains spaces and ` (x86)` gets a quoted fix that switches first.
- `line_path` handles a note, a backticked path and ` (x86)` inside a path.
- No warning when the checkout is up to date, the line is missing, the line is `none`, the path is outside a checkout, or the folder is missing.

`py -3 -I tests/test_relay.py` and `claude plugin validate .` both pass.
