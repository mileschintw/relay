Closes #207

## What

`ready` no longer checks the PR body draft of a done lane outside plan.md's Now table once its PR has merged. After the merge the draft can no longer change anything. A lane like career-log's 575, whose PR said `Part of #575` with no `Closes` line on purpose, used to show as Inconsistent on every run, and nothing could clear it.

## How

- `plugin/tools/relay.py` `ready_done`: for a moved lane, the PR list is looked up before the deny-list and PR body checks. When a PR merged, the lane goes straight to Merged, so `cmd_ready` counts it as left out. Lanes in Now, and moved lanes whose PR is open or missing, take the same path as before.
- `ready`'s help text (the Merged section) and the `ready_done` docstring say so.
- `tests/test_relay.py` `ReadyTests.test_merged_lane_outside_now_gets_no_pr_body_check` covers four cases with a draft that has no `Closes` line:
  - merged, outside Now: not Inconsistent, left out;
  - merged, in Now: still flagged;
  - outside Now with an open PR: still flagged;
  - outside Now with no PR: still flagged.
